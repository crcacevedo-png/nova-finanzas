# RCA — Colección `surgeries` vacía en PRODUCCIÓN

## Problema reportado
El usuario reporta que producción (admin.novavision.me / novavision-finanzas) no contiene las 192 cirugías reales (octubre 2026 – enero 2027) que se cargaron en el entorno de preview mediante un script manual.

## Diagnóstico (solo lectura)
Consulta directa a la base de datos de producción del run activo `fc895316-a8b6-4fc9-8f49-7022fdd2a0d0` (db: `novavision-finanzas-test_database`):

- `surgeries` → **count = 0** (colección existe, vacía; no es collection_not_found).
- `find` en `surgeries` con projection {date, patient_name, institution} → 0 documentos, sin muestra posible.
- `surgery_candidates` → count = 0.
- `surgery_crm` → count = 1.

Ninguna colección relacionada contiene las 192 cirugías.

## Causa raíz
El script manual de carga de las 192 cirugías reales se ejecutó únicamente contra la base de datos del entorno de PREVIEW. Nunca se ejecutó contra la base de datos de PRODUCCIÓN. En los redeploys (type=redeploy) la plataforma NO migra datos de preview a producción (la migración solo ocurre en el deploy inicial type=initial), por lo que los datos cargados en preview después del deploy inicial no se propagan automáticamente. Resultado: la colección `surgeries` de producción quedó vacía.

## Fix sugerido (no aplicado — diagnóstico solo lectura)
El usuario debe llevar los datos a producción, por una de dos vías:
1. Copiar los datos de preview → producción mediante el DB Manager del panel de despliegue, o
2. Re-ejecutar el script de carga apuntándolo explícitamente al MONGO_URL de PRODUCCIÓN (no al de preview).

No se modificó ningún dato durante este diagnóstico.
